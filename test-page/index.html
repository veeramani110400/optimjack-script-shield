Third-party script injection

Loads a pretend vendor script that injects two scripts from other domains. One is on the blocklist and should be blocked; the other should only trigger a warning.

Inline payload fallback

Some infected snippets carried a full copy of the payload that runs through eval when the attacker’s domain is blocked. This test runs a harmless stand-in that sets the same global marker.
